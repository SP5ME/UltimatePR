Manual

  • Terminal jest głównym miejscem pracy. Najpierw wybierz port radiowy i połącz się z korespondentem.
  • Korespondent może wysłać w osobnej linii /I, /MH, /H lub /?, aby otrzymać automatyczną odpowiedź.
  • Komenda I lub INFO zwraca podstawowe dane stacji.
  • W zakładce Stacja edytujesz znak, imię operatora, lokator, QTH oraz gotowe wiadomości.
  • Ikony w górnym pasku służą do motywu, dźwięku, informacji i historii zmian.
  • BBS i NODE są nadal w tle rozwoju, więc na razie skupiamy się na terminalu.

Tożsamość i magazyn BBS

    
Beacon BBS
Gdy BBS jest włączony, jego beacon jest wysyłany automatycznie co 10 minut, z przesunięciem 5 minut względem beaconu stacji. Używa znaku BBS i danych stacji operatora.

    
Forwarding poczty

    
Zdalne endpointy
Wspólne cele dla BBS i Service Routera. Szczegóły połączenia nie muszą być powtarzane w peerze.

    
Partnerzy BBS
Połączenie przez node albo bezpośredni Telnet, zwykle port 7300.

  

  

    
Podręcznik prowadzi przez pierwszą konfigurację, routing i diagnostykę noda.

    
Tożsamość noda
Podstawowe ustawienia NODE. Znak i SSID tworzą adres AX.25, a Alias jest krótką nazwą noda.

    
NET/ROM
Zaawansowane informacje o trasach. Po wyłączeniu NET/ROM poniższe ustawienia nie są używane.
Pomoc NET/ROM
Quality określa preferencję trasy w zakresie 0–255. To nie jest RSSI ani siła sygnału. Obsolescence jest licznikiem cykli dla tras nauczonych automatycznie; po wygaśnięciu trasa jest usuwana. Przykład: trasa 220 jest preferowana przed trasą 180.

    
Wiadomości NODE
Makra: {CALL} {REMOTE}
Makra: {CALL} {REMOTE}

    
Bezpośredni sąsiedzi
Inne nody, z którymi ten node może połączyć się bezpośrednio.
Przykład: SR5XYZ-5 przez VHF-1200. Interfejs jest wybierany z konfiguracji UltimatePR.

    
Trasy ręczne
Ręcznie wskazują, przez którego sąsiada node ma próbować dotrzeć do celu.
Przykład: Cel KRK01 → przez WAW01 → preferencja 180.

  

  

    
Porty TNC i radiowe
Podaj adres i port TNC. Włączenie TNC Proxy udostępnia ten sam KISS TNC wielu aplikacjom; aplikacje zewnętrzne łączą się z adresem IP UltimatePR i podanym portem klientów.

  

  

    
Wiadomości terminala
Powitanie jest wysyłane, gdy operator ma otwarty panel WWW. Nieobecny jest używane podczas pracy stacji w tle. Pożegnanie idzie przy rozłączeniu, a info odpowiada na /I.
Makra: {CALL} {NAME} {LOC} {QTH} {REMOTE}

    
Terminal i AX.25
Parametry tekstowego terminala i połączeń radiowych. Jeżeli nie masz uzgodnionych innych wartości dla swojej sieci, pozostaw ustawienia domyślne.

  

  

    
Panel WWW
Adres, pod którym działa panel administracyjny UltimatePR.

    
Dostęp sieciowy
Dozwolone adresy przyjmują pojedyncze IP, sieci CIDR lub nazwy hostów, oddzielone przecinkami. Lista dotyczy panelu WWW oraz klientów TNC Proxy. Wartość 0.0.0.0 zezwala na każdy adres IPv4.

    
Użytkownik panelu
Dane logowania są zapisywane oddzielnie i nie wymagają restartu UltimatePR. Po zapisaniu nastąpi wylogowanie.

  

  

    
Publiczne API
Wersjonowane API tylko do odczytu dla Home Assistant, monitoringu i zewnętrznych integracji. Korzysta z tego samego adresu i portu co panel WWW.
Zmiana wymaga ponownego uruchomienia UltimatePR. Adres nasłuchu i dozwoloną podsieć można zmienić bez ręcznej edycji YAML.
Otwórz dokumentację API

    
Tokeny API
Token jest pokazywany tylko raz. UltimatePR zapisuje wyłącznie jego hash SHA-256. Dla Home Assistant wybierz gotowy profil odczytu.
Skopiuj token teraz — nie będzie można wyświetlić go ponownie.

  

  

  
Tryb pracy
NODE i BBS stanowią jeden wspólny tryb i są zawsze włączane lub wyłączane razem.

  
Funkcje eksperymentalne
Mapa i nadrzędny przełącznik usług są eksperymentalne. UPRdirect ma własny niezależny przełącznik w zakładce „UPRdirect”.
