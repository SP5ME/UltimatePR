UltimatePR API v1

Read-only telemetry API. Send Authorization: Bearer TOKEN to protected endpoints.

OpenAPI 3.1 specification

Endpoints

  • GET /api/v1/health
  • GET /api/v1/status
  • GET /api/v1/ports[/{id}]
  • GET /api/v1/mheard[/{callsign}] and /summary
  • GET /api/v1/sessions
  • GET /api/v1/monitor?limit=100&direction=rx&port=...
  • GET /api/v1/node/status
  • GET /api/v1/bbs/status
  • GET /api/v1/digipeater/status
  • WebSocket /api/v1/events
